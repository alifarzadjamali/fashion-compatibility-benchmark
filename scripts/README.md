# Benchmark scripts

The current pipeline lives in [v2/](v2/). Its GPU entry point, [run_full_gpu.sh](v2/run_full_gpu.sh), runs extraction, training, inference and profiling. Its CPU entry point, [run_full_cpu.sh](v2/run_full_cpu.sh), runs the probes and statistical analyses.

The top-level scripts in this directory belong to the v1 pilot and are kept for reproducing it.
