# RepBench-Fashion v2 — Paper-writing guide

Status: **SKELETON** (drafted 2026-11-20 during Phase 2). Sections marked _TODO (after run)_
are filled when the full run is finished, copied and verified.

Use this file to write the paper without re-deriving anything: every number, table and
figure comes from a generated file listed here; every claim about provenance points to a
hash in a committed file.

---

## 0. Ground rules for writing

1. **Never type a number.** Use `\input{numbers.tex}` macros (generated by
   `scripts/v2/make_tables_v2.py`); `scripts/v2/check_paper_numbers.py` fails the build on
   hand-typed values.
2. **Figures and tables are generated** (`make_figures_v2.py`, `make_tables_v2.py`). If a
   figure needs a change, change the script and regenerate.
3. **Model choices quoted in the text** (best generic / best fashion) come from
   `selection.json` — validation-only, never test.
4. **Deviations** go in the deviation table (§6), all of them, briefly.
5. Venue: Elsevier IVC (mirror to Springer MVA). Manuscript sources:
   `paper_elsevier_ivc/`, `paper_springer_mva/`. HANDOFF_V2.md §10 lists the editorial
   changes, citation fixes and the submission package.

## 7. Regenerating everything (laptop, no DGX needed)

```bash
R=~/repbench-results
.venv/bin/python scripts/v2/make_tables_v2.py --results $R/results --out $R/generated
.venv/bin/python scripts/v2/make_figures_v2.py --results $R/results --out $R/figures \
  --mllm $R/mllm/polyvore_v2_clean $R/mllm/iqon3000_v2_clean $R/mllm/pog_v2_clean
.venv/bin/python scripts/v2/check_paper_numbers.py --generated $R/generated
```
Probes/statistics can be re-run on the laptop from `~/repbench-results/emb` and
`~/repbench-results/protocols` (verified: E3, |ΔAUC| 2e-6 vs DGX).
